# Kémzy Combat Arena

An Android-first, standalone shooter skills training simulator. It is an independent training app and does not modify, inject into, automate, or interact with a live Free Fire session.

## Training drills
- Movement and joystick control
- Aim and tap-to-fire practice
- Jumping, crouching and dodging
- Gloo-wall placement practice
- Multiple target drills and a simple score counter

## Build
The GitHub Actions workflow builds a debug APK and uploads it as an artifact. Open the **Actions** tab, select **Build Android APK**, run the workflow if needed, and download the `kemzy-combat-arena-debug-apk` artifact.

This is an early prototype. It uses original placeholder graphics and is not a full 3D game yet.
